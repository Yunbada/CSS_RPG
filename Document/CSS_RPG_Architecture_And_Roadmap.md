# CSS_RPG: 아키텍처 및 상세 개발 로드맵 (개정판)

본 문서는 프로젝트의 스크립트 기반 실진행도를 반영하여 갱신된 **가장 자세한 최신 로드맵**입니다. 

---

## ✅ 1. 현재 완료된 작업 (Completed)

**Phase 1: 기반 아키텍처 고도화**
- **타격 판정의 추상화 (`IDamageable`)**: 하드코딩 탈피, 다형성 기반 데미지 체계 완료.
- **전투 상태 머신 (FSM) 적용**: Idle, Attacking, SkillCasting 등 상태 기반 액션 락 적용 완료.

**Phase 2: 콘텐츠 수평 확장**
- **다양한 직업 스킬 실행기 (`ISkillExecutor`) 구현**: `Fighter`, `Swordsman`, `Mage` 뿐만 아니라 **`PaladinSkillExecutor`까지 확장이 완료**되었습니다.
- 직업별 다이나믹 바인딩 및 동기화 구조 확보 완료.

**Phase 4: 인벤토리 및 데이터 주도 시스템 (우선 진행됨)**
- **엑셀(CSV) 기반 데이터베이스 (`ItemDatabase`)**: `ItemDatabase.csv`, `RecipeDatabase.csv` 파일 파싱 및 메모리 캐싱 완료.
- **아이템 루팅 시스템 (`InventorySystem`)**: 좀비 사망 시 `ItemDatabase`의 가중치(DropWeight)에 따른 랜덤 드롭 획득 로직 구현.
- **인벤토리 동기화 (`InventorySystem`)**: 슬롯 배열 기반 관리 및 네트워크 변수 직렬화 동기화, 영구 저장 연동 등 주요 뼈대 완료.

---

## 🚀 2. 상세 로드맵 (Actionable Roadmap)

현재 진행 상황을 바탕으로, 앞으로 수행해야 할 남은 작업들입니다.

### Phase 4-4: 3D 드롭 아이템(Looting) 시각화 및 인벤토리 연동
*   [ ] **드롭 아이템의 3D 시각화 및 자동 획득 구현 (현재 목표)**
    *   좀비 처치 시, 극히 낮은 확률로 좀비 위치에 3D 큐브(크기 0.3)를 스폰합니다. (큐브 모델은 추후 다른 모델로 교체 예정)
    *   스폰된 큐브에 플레이어가 다가가서 접촉(Trigger)하면 즉시(자동으로) 획득되어 `InventorySystem`에 아이템이 추가되도록 네트워크 획득 로직을 구현합니다.
*   [ ] **실시간 인벤토리 UI 구성**
    *   서버에서 관리 중인 `InventorySystem`의 슬롯 정보가 실제 화면 슬롯 이미지(아이콘)와 수량 텍스트로 즉각 반영되도록 이벤트 연동 작업이 필요합니다.
